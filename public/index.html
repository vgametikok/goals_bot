Метки

Выберите дни недели — задача появится в эти дни каждую неделю.

Настройки

Данные сохраняются на сервере для вашего аккаунта Telegram. Часовой пояс сетки: МСК. Сетка: 00:00–24:00, по умолчанию открывается около 08:00 — прокрутите колёсиком вверх/вниз.

  • Перетаскивайте карточки на другой день или время
  • Клик по пустой ячейке — новая задача
  • Клик по карточке — редактирование; в форме — Удалить / Скопировать
  • Галочка на карточке — статус «выполнено»
  • При удалении категории задачи автоматически переносятся в первую оставшуюся

Категории

Верхние вкладки. Добавьте категории сами. Можно менять название и цвет. При удалении должна остаться хотя бы одна.

Метки

Метки на карточках — создайте свои. Статус «выполнено» — отдельно, через галочку, здесь не редактируется.
