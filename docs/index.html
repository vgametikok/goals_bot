Данные хранятся локально в браузере (localStorage). Часовой пояс сетки: МСК. Сетка: 00:00–24:00, по умолчанию открывается около 08:00 — прокрутите колёсиком вверх/вниз.

  • Перетаскивайте карточки на другой день или время (на телефоне — долгое нажатие или «Переместить»)
  • Клик / касание пустой ячейки — новая задача
  • Клик / касание карточки — редактирование; в форме — Удалить / Скопировать
  • Галочка на карточке — статус «выполнено»
  • При удалении категории задачи автоматически переносятся в первую оставшуюся
